# Create a React Vite App

Run the following command to create a new React app using Vite:

```bash
npm create vite@latest
```

Then follow the prompts:

1. Enter your **project name**.
2. Select **React** as the framework.
3. Select **JavaScript** as the variant.
4. Select **Oxlint** as the linter.

## Start the Project

Navigate to your project directory:

```bash
cd <project-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Recommended VS Code Extension

For easier React development, install the **ES7+ React/Redux/React-Native Snippets** extension in Visual Studio Code.

### Installation

1. Open **Visual Studio Code**.
2. Open the **Extensions** panel.
3. Search for **ES7+ React/Redux/React-Native Snippets**.
4. Install the extension.
5. Restart VS Code if required.

The extension provides useful shortcuts for quickly creating React components and common React code patterns.
